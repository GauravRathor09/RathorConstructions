## 🏗️ About

This is the official website for **Rathor Constructions**, a construction company operating since 2004 across 50+ cities in India, headquartered in Haldwani, Uttarakhand.

---

## ✨ Features

- **Animated Intro Splash** — branded loading screen with progress bar
- **Sticky Navigation** — transparent → frosted-glass on scroll, mobile hamburger menu
- **Hero Section** — fullscreen background, typewriter subtitle, scroll-triggered animations
- **Stats Counter** — animated number counters on scroll-in
- **Cost Estimator** — 5-step interactive construction cost calculator with breakdown charts
- **Before / After Slider** — drag-to-compare renovation transformations
- **Project Portfolio** — hover-reveal project cards
- **Process Timeline** — 6-stage alternating timeline
- **FAQ Accordion** — animated expand/collapse
- **Contact Form** — WhatsApp-integrated lead submission
- **Lead Popup** — triggered at 60% scroll depth (once per session)
- **Floating Buttons** — WhatsApp chat + call + back-to-top
- **Scroll Progress Bar** — top-of-page reading indicator
- **Fully Responsive** — mobile, tablet, desktop

## 🚀 Getting Started

### Local Development

No build tools or dependencies needed. Just open `index.html` in your browser:

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/rathor-constructions.git

# Open in browser
cd rathor-constructions
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

Or use VS Code with the **Live Server** extension for hot-reload.

---

## 🌐 Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Under **Source**, select `main` branch → `/ (root)`
4. Click **Save**
5. Your site will be live at `https://YOUR_USERNAME.github.io/rathor-constructions/`
